# AI Slides Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a day-1 paid Nuxt site that turns a topic into a PPTX slide deck under SEO keyword `ai slides`, with Free 1/day and Paid 30 presentations/month at $9/$20/$72.

**Architecture:** Copy Tagtery (`etsy-tag-tool`) into a **new repo**. Keep Auth / Waffo / Aliyun / quota plumbing; replace generate path with LLM→JSON pages→PPTX; change paid metering from “unlimited/day” to **30/month**. Launch infra via **ship-paid-site** (new Supabase project, never reuse Tagtery).

**Tech Stack:** Nuxt 3, Vue 3, DeepSeek Flash (`deepseek-flash`), pptxgenjs, Supabase Auth, Waffo Pancake, Vercel, Cloudflare, Aliyun DirectMail.

**Spec:** `docs/superpowers/specs/2026-10-10-ai-slides-design.md`

## Global Constraints

- Product is English-first UI; slide content language follows user topic.
- Model: `deepseek-flash` only for MVP (env `LLM_MODEL`).
- Pricing fixed: Free $0 (1/day, ≤5 pages, watermark); Monthly $9 / Quarterly $20 / Annual $72 (30 presentations/month, ≤12 pages, no watermark).
- Hidden anti-abuse: ≤10 generations/day on paid; `max_tokens` ≤ 4000.
- Table prefix: `aislides_` (not `tagtool_`).
- New Supabase project per site; do not reuse Tagtery/aiflowcard.
- Carry Tagtery auth/checkout behaviors verbatim (login gate checkout, confirm email off, reset-password flow).
- Secrets never committed; use `.env` / Vercel env only.
- Brand placeholders until Task 0 filled: `BRAND`, `APEX`, `SUPPORT_EMAIL`.

import test from 'node:test'
import assert from 'node:assert/strict'

function monthKey(d = new Date()) {
  return d.toISOString().slice(0, 7) // YYYY-MM
}

function remainingPaid(used, monthlyCap = 30, dailyUsed = 0, dailyCap = 10) {
  const monthLeft = Math.max(monthlyCap - used, 0)
  const dayLeft = Math.max(dailyCap - dailyUsed, 0)
  return Math.min(monthLeft, dayLeft)
}

test('monthKey is YYYY-MM', () => {
  assert.equal(monthKey(new Date('2026-10-10T12:00:00.000Z')), '2026-10')
})

test('paid remaining respects month and day caps', () => {
  assert.equal(remainingPaid(0, 30, 0, 10), 10)
  assert.equal(remainingPaid(28, 30, 0, 10), 2)
  assert.equal(remainingPaid(5, 30, 9, 10), 1)
  assert.equal(remainingPaid(30, 30, 0, 10), 0)
})
